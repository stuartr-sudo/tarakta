## 2. Why the bot wasn't profitable (all verified 2026-07-18)

Instance `tarakta-mm`, May 1 → Jul 16: −$9,660. Mechanisms, ranked:

1. **No selection layer since Apr 28.** The 97%-veto Opus agent era
   (Apr 20–27) was the only profitable configuration. From June 15 every LLM
   call logged `ERROR client_unavailable` (no API key) — silently converted
   to APPROVE by shadow mode. FIXED: CLI backend + token (above).
2. **Candidate quality is the root problem.** F/C-grade, sideways-HTF setups
   pass the gates (worst two losers were Grade F). Confluence: 16 factors,
   4 dead (~0% fire, incl. stopping_volume 15pts), news stub never fires;
   dead weight stays in the denominator → real ceiling ~74% → everything
   grades C. The +$91k dead-factor zero-out was never shipped (gate: verify
   per-factor fire rates first, CODEX_PLAN Task 0.4).
3. **Exit mechanics leak ~$5–6k/quarter:** stops fill at −1.39R avg (soft
   stop polled every 5 min, tight SLs); BE-ladder arms on Level-2 advance
   which almost never fires (36/41 stops never armed BE despite MFE up to
   5R); scratch rule closes at market at 2h (7 closes worse than −0.3R =
   −$2.4k).
4. Fee/accounting inconsistencies (prod fees ~$0 recorded; `trades.pnl_usd`
   IS cumulative incl. partials — never add `partial_exits` on top).

## 6. Gotchas discovered this session (beyond CLAUDE.md's list)

- `~/.zshrc` used to export an EMPTY `SSL_CERT_FILE` (Homebrew python3 lost
  certifi) — broke TLS for ALL Node tools in login shells. Line is commented
  out; if TLS errors reappear, check for its return. Run one-off CLI probes
  with `env -u SSL_CERT_FILE`.
- The `claude` CLI can exit 0 with `is_error:true` inside its JSON — always
  check the flag. Models append prose after fenced JSON —
  `MMCommittee._extract_json` uses incremental `raw_decode` (keep it).
- Keychain CLI login on this Mac 401s (desktop app auth is separate) — the
  `.env` token is the reliable path; also the future Fly secret.
- `mm_agent_decisions.cost_usd` for CLI-backend rows is the CLI's
  informational estimate (subscription quota, not dollars).
- Nested-session env markers (`CLAUDE_CODE_*`, `ANTHROPIC_BASE_URL`) corrupt
  child CLI auth — `mm_claude_cli._ENV_STRIP` scrubs them; keep it.
- launchd restarts the bot ~instantly on kill (KeepAlive) — "stopping" the
  local bot means `launchctl unload`, not `kill`.
- Committee replay/backtest scripts write NO DB rows (they call
  `_run_committee` directly); only `e2e_committee.py` writes one real row.
